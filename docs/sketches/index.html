Сравнение вариантов

Вариант Фокус Сложность внедрения Когда брать
0. Сейчас Всё на виду — База до рефакторинга UI
1. Карточки + сцена Иерархия модель / действие / результат Низкая Первый шаг после РКЧХ
2. Холст графиков Максимум площади под отклики Средняя Если анализ — главный сценарий
3. Сайдбар ID Workflow «файл → модель» Средняя Идентификация как вход в сессию
4. Синтез + режимы Вручную / авто / РКЧХ в одной вкладке Средняя Когда РКЧХ готов
5. ПФ чтение/правка Красивая формула + компактный edit Средняя–высокая Главная «боль» формы ПФ

Практичная комбинация: 1 + 5 на всех вкладках, 3 для идентификации, 4 для синтеза. Вариант 2 — опционально как «режим фокуса» на анализе.
